# ¡Bienvenido a la Documentación de Vanguard

:::warning Documentación en Desarrollo
Esta documentación **está escrita por la comunidad de Vanguard** y **supervisada por su equipo de desarrollo**. Si tiene alguna duda, **le recomendamos consultar nuestro servidor de soporte**.
:::

En esta documentación aprenderás **todas las opciones disponibles para personalizar en profundidad a Vanguard** y sacar todo su potencial.

## Un Bot Multifuncional Diferente

A diferencia de otros bots de Discord multifuncionales, la configuración de Vanguard se basa en **configurar un archivo YAML para cada funcionalidad** diferente.

Este tipo de configuración permite a los usuarios **diseñar sistemas completamente personalizados** para satisfacer las necesidades de sus comunidades de Discord.

:::tip Conocimiento Previo en YAML
Rogamos encarecidamente que los usuarios **tengan un conocimiento previo en YAML**. En caso contrario, [**le recomendamos ver el siguiente video**](https://www.youtube.com/watch?v=BEki_rsWu4E).
:::
