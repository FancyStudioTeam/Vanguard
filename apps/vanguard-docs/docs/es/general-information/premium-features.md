# Funcionalidades Premium

Para **garantizar el correcto funcionamiento de Vanguard** en todas las comunidades de Discord, **ofrecemos diferentes funcionalidades premium** en los distintos plugins que ofrecemos.

## Configuración de Funcionalidades Premium

Los usuarios **podrán configurar las funcionalidades premium**, pero dichas funcionalidades **serán ignoradas en la ejecución** en caso de que la comunidad **no posea una membresía premium de Vanguard**.

## Decisión de Funcionalidades Premium

Dependiendo del impacto que tenga una funcionalidad en la API de Discord o dentro de la comunidad, las opciones podrán ser marcadas como premium.
